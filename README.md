# Number Analyzer 🔢

Простой и быстрый Python-скрипт для анализа свойств целых чисел. Отличный базовый инструмент, который принимает на вход число и выдает по нему полную сводку.

## ⚙️ Функционал

Скрипт проводит проверку введенного числа по следующим параметрам:
- **Знак:** определяет, положительное это число, отрицательное или ноль.
- **Четность:** проверяет, является ли число четным или нечетным.
- **Делимость:** проверяет, делится ли число на 3 и на 5 без остатка.
- **Простое число:** математическая проверка на то, является ли число простым (используется оптимизированный алгоритм поиска делителей до квадратного корня).
- **Количество цифр:** подсчитывает, из скольких цифр состоит число (минус у отрицательных чисел не учитывается).

Также встроена базовая защита от некорректного ввода: если пользователь введет текст или символы вместо числа, скрипт перехватит ошибку `ValueError` и попросит повторить попытку.

## 🚀 Как запустить

Для работы скрипта нужен только установленный Python 3. Дополнительные библиотеки скачивать не нужно.

1. Склонируй репозиторий или скачай файл со скриптом (например, `number_check.py`).
2. Запусти скрипт через терминал:

```bash
python number_check.py
